# CouponX

A simple coupon exchange website using pure Python (No Frameworks) and Data Structures.

## How to Run
1. Ensure Python 3 is installed.
2. Run the server:
   ```bash
   python main.py
   ```
3. Open http://localhost:8080

## Credentials
- Admin: `admin` / `admin123`
- Register new users as needed.

## Structure
- `main.py`: The HTTP Server and Logic.
- `core/`: Logic and Data Classes (User, Coupon, DataManager).
- `data/`: Storage (JSON files).
- `templates/`: HTML files.
- `public/`: CSS and assets.
